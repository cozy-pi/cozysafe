Cozy Safe

隱私權政策

最後更新：2026-10-19

摘要

Cozy Safe 不會收集、傳送或出售你的任何資料。App 中沒有帳號、沒有分析、沒有廣告，也沒有追蹤。

你放進保險箱的所有內容都會在你的裝置上加密。我們無法讀取這些內容，也沒有任何副本。

保留在你裝置上的內容

你的保險箱、筆記、檔案和相片，一律以由你的密碼和 Secret Key 衍生的金鑰加密。

App 設定，例如語言及淺色或深色模式。

資料可能前往之處（僅限你選擇時）

同步和備份會使用你選擇的資料夾或裝置（例如 iCloud 雲碟、Google 雲端硬碟、Dropbox，或你網路中的其他裝置）。寫入其中的只有加密資料，你選擇的服務供應商無法讀取。

如果你開啟 Secret Key 同步，Secret Key 會儲存在你所用平台的端對端加密密碼庫（iCloud 鑰匙圈或 Google 密碼管理工具）中，並受該供應商的隱私權條款規範。

當你在其他 App 中分享、匯出或開啟項目時，該 App 會收到一份未加密的副本，並依其本身的條款處理。

權限

相機：僅在你開啟相機時，用來將相片直接拍進保險箱。相片不會儲存到你的相簿。

生物辨識：僅在你開啟 Face ID、Touch ID 或指紋解鎖時使用。你的生物辨識資料絕不會離開裝置的安全硬體，App 也始終無法取得。

本網站

safe.cozypi.com 是一組由 Cloudflare 提供服務的靜態網頁。本網站不設定 Cookie，也不執行任何分析。基於安全考量，Cloudflare 可能依其本身的隱私權政策保留標準技術記錄（例如 IP 位址）。下載檔案由 GitHub 提供。

兒童

Cozy Safe 並非以 13 歲以下兒童為對象，且不會向任何人收集資料。

政策變更與聯絡方式

如果本政策有所變更，新版本會發布在本頁面並標示新的日期。
