Cozy Safe 如何保護你

你的資料不會以未加密的形式離開裝置，負責加密的程式碼也完全公開。

在裝置上加密

資料在寫入磁碟之前就已加密，因此存放在雲端資料夾中的備份同樣是加密的。

保險箱密碼加上復原金鑰

你的保險箱密碼會與一組隨機的 256 位元復原金鑰（24 個單字）結合，因此即使有人取得你的備份副本，也無法猜出密碼。

沒有伺服器，不需要帳號

Cozy Safe 沒有自己的伺服器。只有在你開始同步並允許時才會連線：連到同一 Wi-Fi 下你自己的裝置，或你自己的 Google Drive。所有傳送的內容都會加密。

螢幕上也不外露

密碼和復原金鑰在你點選「顯示」之前都會隱藏，複製的文字 60 秒後自動清除，離開 App 後保險箱會立即鎖定。

備份由你掌控

將所有保險箱備份成一個加密檔案，並在新裝置上用復原金鑰和保險箱密碼開啟。資料不會傳到我們的伺服器，我們也沒有伺服器。

開放原始碼

任何人都能閱讀和檢查程式碼（GPL-3.0）。安裝檔由 GitHub 建置，並附有可驗證的來源證明。

使用前須知

無法復原

  • 如果遺失復原金鑰或保險箱密碼，任何人都無法打開你的備份，包括我們。
  • 請選一組你記得住的密碼，例如由幾個詞組成的片語。

它做不到的事

  • 同步是新功能，Google Drive 同步目前僅支援 iPhone：請經常備份成檔案。
  • 無法保護已經感染惡意軟體的裝置。
  • 任何知道密碼的人都能打開保險箱。
