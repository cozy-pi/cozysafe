スマートフォン、タブレット、パソコンで

Cozy Safe があなたを守るしくみ

データが暗号化されないままデバイスの外に出ることはありません。その処理を行うコードも公開されています。

デバイス上で暗号化

データはディスクに書き込まれる前に暗号化されます。そのため、クラウドフォルダに置いたバックアップも暗号化されたままです。

パスワード ＋ Secret Key

パスワードは、デバイスに保管されたランダムな 128 ビットの鍵と組み合わされます。そのため、金庫のコピーを手にした人でもパスワードを推測できません。

完全オフライン

Cozy Safe はネットワークを必要としません。Android ではインターネット権限を一切持たず、macOS ではネットワークにアクセスできないサンドボックス内で動作します。

画面上でも見せない

パスワードと Secret Key は「表示」をタップするまで隠され、コピーしたテキストは60秒後に消去されます。アプリを離れるとすぐに金庫がロックされます。

自分で管理できるバックアップ

金庫全体をひとつの暗号化ファイルにバックアップし、緊急キットを使って新しいデバイスに復元できます。私たちのサーバーには何も送られません。そもそもサーバーがありません。

オープンソース

コードは誰でも読んで確認できます（GPL-3.0）。インストーラは GitHub でビルドされ、その出所を検証できます。

はじめに知っておいてほしいこと

復元はできません

  • パスワードを忘れると、私たちを含め誰も金庫を開けられなくなります。
  • いくつかの単語をつなげたフレーズなど、忘れないパスワードを選んでください。

できないこと

  • デバイス間の同期はまだありません。こまめにファイルへバックアップしてください。
  • すでにマルウェアに感染しているデバイスは守れません。
  • パスワードを知っている人は誰でも金庫を開けられます。

Apple による署名と公証済みです。ディスクイメージを開き、Cozy Safe を「アプリケーション」フォルダにドラッグしてください。

ダウンロードCozySafe-macos.dmg
Windows

まだ署名されていません。SmartScreen の警告が出たら、［詳細情報］→［実行］の順に選んでください。

ダウンロードCozySafe-windows-x64.zip
Linux

展開して ./cozysafe を実行します。GTK 3 と libsecret が必要です。

ダウンロードCozySafe-linux-x64.tar.gz
