Cozy Safe

プライバシーポリシー

最終更新日：2026-10-19

概要

Cozy Safe は、お客様のデータを一切収集、送信、販売しません。アプリにはアカウント、分析、広告、トラッキングはありません。

金庫に入れたものはすべてお客様のデバイス上で暗号化されます。私たちはその内容を読むことができず、コピーも保有していません。

デバイスに保存されるもの

金庫、メモ、ファイル、写真。これらは常に、パスワードと Secret Key から導出された鍵で暗号化されています。

言語やライト／ダークモードなどのアプリ設定。

データの送信先（お客様が選んだ場合のみ）

同期とバックアップには、お客様が選んだフォルダまたはデバイス（例：iCloud Drive、Google ドライブ、Dropbox、同じネットワーク上の別のデバイス）を使用します。そこに書き込まれるのは暗号化されたデータだけで、選んだプロバイダはその内容を読むことができません。

Secret Key の同期をオンにすると、Secret Key はお使いのプラットフォームのエンドツーエンド暗号化されたパスワード保管庫（iCloud キーチェーンまたは Google パスワード マネージャー）に、そのプロバイダのプライバシー規約に基づいて保存されます。

項目を共有、書き出し、または別のアプリで開くと、そのアプリは暗号化されていないコピーを受け取り、そのアプリ自身の規約に基づいて取り扱います。

アクセス許可

カメラ：お客様がカメラを開いたときに、写真を直接金庫に撮影するためにのみ使用します。写真は写真ライブラリには保存されません。

生体認証：Face ID、Touch ID、または指紋によるロック解除をオンにした場合にのみ使用します。生体認証データがデバイスのセキュアなハードウェアの外に出ることはなく、アプリから利用できることもありません。

このウェブサイト

safe.cozypi.com は、Cloudflare が配信する静的ページで構成されています。Cookie は設定せず、分析も実行しません。Cloudflare は、セキュリティのために標準的な技術ログ（IP アドレスなど）を、同社のプライバシーポリシーに基づいて保持する場合があります。ダウンロードファイルは GitHub から配信されます。

お子様について

Cozy Safe は 13 歳未満のお子様を対象としておらず、どなたからもデータを収集しません。
