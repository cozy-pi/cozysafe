นโยบายความเป็นส่วนตัว

อัปเดตล่าสุด 2026-10-19

โดยสรุป

Cozy Safe ไม่เก็บรวบรวม ส่ง หรือขายข้อมูลใดๆ ของคุณ ในแอปไม่มีบัญชี ไม่มีการวิเคราะห์ข้อมูล ไม่มีโฆษณา และไม่มีการติดตาม

ทุกสิ่งที่คุณเก็บไว้ในตู้นิรภัยจะถูกเข้ารหัสบนอุปกรณ์ของคุณ เราอ่านไม่ได้และไม่มีสำเนาใดๆ

สิ่งที่อยู่บนอุปกรณ์ของคุณ

ตู้นิรภัย โน้ต ไฟล์ และรูปภาพของคุณ ซึ่งเข้ารหัสเสมอด้วยคีย์ที่สร้างจากรหัสผ่านและ Secret Key ของคุณ

การตั้งค่าแอป เช่น ภาษา และโหมดสว่างหรือมืด

ที่ที่ข้อมูลของคุณอาจไป เฉพาะเมื่อคุณเลือก

การซิงค์และการสำรองข้อมูลใช้โฟลเดอร์หรืออุปกรณ์ที่คุณเลือก (เช่น iCloud Drive, Google ไดรฟ์, Dropbox หรืออุปกรณ์อื่นในเครือข่ายของคุณ) สิ่งที่เขียนไปที่นั่นมีเพียงข้อมูลที่เข้ารหัสแล้ว ผู้ให้บริการที่คุณเลือกจึงอ่านไม่ได้

หากคุณเปิดการซิงค์ Secret Key ระบบจะเก็บ Secret Key ไว้ในที่เก็บรหัสผ่านแบบเข้ารหัสตั้งแต่ต้นทางถึงปลายทางของแพลตฟอร์มของคุณ (พวงกุญแจ iCloud หรือเครื่องมือจัดการรหัสผ่านของ Google) ภายใต้ข้อกำหนดด้านความเป็นส่วนตัวของผู้ให้บริการรายนั้น

เมื่อคุณแชร์ ส่งออก หรือเปิดรายการในแอปอื่น แอปนั้นจะได้รับสำเนาที่ไม่ได้เข้ารหัส และจัดการตามข้อกำหนดของแอปนั้นเอง

สิทธิ์การเข้าถึง

กล้อง: ใช้เฉพาะเพื่อถ่ายรูปเก็บเข้าตู้นิรภัยโดยตรงเมื่อคุณเปิดกล้อง รูปภาพจะไม่ถูกบันทึกลงในคลังรูปภาพของคุณ

ข้อมูลชีวมิติ: ใช้เฉพาะเมื่อคุณเปิดการปลดล็อกด้วย Face ID, Touch ID หรือลายนิ้วมือ ข้อมูลชีวมิติของคุณไม่เคยออกจากฮาร์ดแวร์ความปลอดภัยของอุปกรณ์ และแอปไม่สามารถเข้าถึงได้เลย

เว็บไซต์นี้

safe.cozypi.com เป็นชุดหน้าเว็บแบบสแตติกที่ให้บริการโดย Cloudflare เว็บไซต์นี้ไม่ตั้งค่าคุกกี้และไม่ใช้เครื่องมือวิเคราะห์ใดๆ Cloudflare อาจเก็บบันทึกทางเทคนิคมาตรฐาน (เช่น ที่อยู่ IP) เพื่อความปลอดภัย ภายใต้นโยบายความเป็นส่วนตัวของ Cloudflare เอง ไฟล์ดาวน์โหลดให้บริการโดย GitHub

เด็ก

Cozy Safe ไม่ได้มุ่งเป้าไปที่เด็กอายุต่ำกว่า 13 ปี และไม่เก็บรวบรวมข้อมูลจากผู้ใดเลย

การเปลี่ยนแปลงและการติดต่อ

หากนโยบายนี้มีการเปลี่ยนแปลง ฉบับใหม่จะเผยแพร่ในหน้านี้พร้อมวันที่ใหม่
