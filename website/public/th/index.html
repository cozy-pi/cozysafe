หลักการทำงานดาวน์โหลดซอร์สโค้ด

ตู้เซฟที่ปลอดภัยสำหรับข้อมูลสำคัญของคุณ

ทุกอย่างถูกเข้ารหัสบนอุปกรณ์ของคุณก่อนบันทึก ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์ แอปจะเชื่อมต่อเฉพาะกับอุปกรณ์ของคุณเองใน Wi-Fi เดียวกันเมื่อคุณซิงค์ หากไม่มีรหัสผ่านของคุณ จะไม่มีใครเปิดได้ รวมถึงเราด้วย

ดาวน์โหลด ดูซอร์สโค้ด
ปลดล็อก •••••••••••• ปลดล็อก ปลดล็อกด้วย Face ID

รุ่นทดลอง Cozy Safe ใช้งานได้บนอุปกรณ์เครื่องเดียว ยังไม่มีการซิงค์ระหว่างอุปกรณ์ ควรใช้ สำรองข้อมูลเป็นไฟล์ บ่อยๆ และตอนนี้อย่าเก็บสำเนาเดียวของสิ่งสำคัญไว้ที่นี่

ทุกอย่างในตู้นิรภัยเดียว

โน้ต รูปภาพ วิดีโอ บันทึกเสียง และไฟล์ทุกประเภท นี่คือหน้าจอจริงของแอปพร้อมเนื้อหาตัวอย่าง

บนโทรศัพท์และแท็บเล็ต

Cozy Safe ปกป้องคุณอย่างไร

ข้อมูลของคุณไม่เคยออกจากอุปกรณ์โดยไม่ได้เข้ารหัส และโค้ดที่ทำหน้าที่นี้เปิดเผยต่อสาธารณะ

เข้ารหัสบนอุปกรณ์ของคุณ

ข้อมูลจะถูกเข้ารหัสก่อนเขียนลงดิสก์ ดังนั้นข้อมูลสำรองที่เก็บไว้ในโฟลเดอร์บนคลาวด์ก็ถูกเข้ารหัสด้วย

รหัสผ่านตู้นิรภัยคู่กับคีย์กู้คืน

รหัสผ่านตู้นิรภัยของคุณจะถูกใช้ร่วมกับคีย์กู้คืนแบบสุ่มขนาด 256 บิต (24 คำ) ดังนั้นแม้มีคนได้สำเนาไฟล์สำรองของคุณไป ก็ยังเดารหัสผ่านไม่ได้

ไม่มีเซิร์ฟเวอร์ ไม่มีบัญชี

Cozy Safe ไม่ติดต่อกับเซิร์ฟเวอร์ใดเลย การเชื่อมต่อเดียวที่แอปทำคือกับอุปกรณ์ของคุณเองใน Wi-Fi เดียวกัน เมื่อคุณเริ่มซิงค์และอนุญาต และทุกอย่างที่ส่งจะถูกเข้ารหัส

ปลอดภัยแม้บนหน้าจอ

รหัสผ่านและคีย์กู้คืนจะถูกซ่อนไว้จนกว่าคุณจะแตะแสดง ข้อความที่คัดลอกจะถูกลบหลัง 60 วินาที และตู้นิรภัยจะล็อกทันทีที่คุณออกจากแอป

การสำรองข้อมูลที่คุณควบคุมเอง

สำรองตู้นิรภัยทุกตู้เป็นไฟล์เข้ารหัสไฟล์เดียว แล้วเปิดบนอุปกรณ์ใหม่ด้วยคีย์กู้คืนและรหัสผ่านตู้นิรภัยของคุณ ไม่มีอะไรถูกส่งไปยังเซิร์ฟเวอร์ของเรา เพราะเราไม่มีเซิร์ฟเวอร์

โอเพนซอร์ส

ทุกคนสามารถอ่านและตรวจสอบโค้ดได้ (GPL-3.0) ตัวติดตั้งสร้างโดย GitHub พร้อมหลักฐานแหล่งที่มาที่คุณตรวจสอบได้

สิ่งที่ควรรู้ก่อน

ไม่มีการกู้คืน

  • หากคุณทำคีย์กู้คืนหรือรหัสผ่านตู้นิรภัยหาย จะไม่มีใครเปิดไฟล์สำรองของคุณได้ รวมถึงเราด้วย
  • เลือกรหัสผ่านที่คุณจำได้ เช่น วลีที่ประกอบด้วยหลายคำ

สิ่งที่ทำไม่ได้

  • ยังไม่มีการซิงค์ระหว่างอุปกรณ์ จึงควรสำรองข้อมูลเป็นไฟล์บ่อยๆ
  • ไม่สามารถปกป้องอุปกรณ์ที่ติดมัลแวร์อยู่แล้ว
  • ใครก็ตามที่รู้รหัสผ่านสามารถเปิดตู้นิรภัยได้

ดาวน์โหลด

ฟรี ไม่ต้องมีบัญชี

macOS

ลงนามและผ่านการรับรอง (notarize) จาก Apple แล้ว เปิดไฟล์ดิสก์อิมเมจ แล้วลาก Cozy Safe ไปไว้ในโฟลเดอร์แอปพลิเคชัน

ดาวน์โหลดCozySafe-macos.dmg
Windows

ยังไม่ได้ลงนาม: หาก SmartScreen แสดงคำเตือน ให้เลือก "ข้อมูลเพิ่มเติม" แล้วเลือก "เรียกใช้ต่อไป"

ดาวน์โหลดCozySafe-windows-x64.zip
Linux

แตกไฟล์แล้วเรียกใช้ ./cozysafe ต้องมี GTK 3 และ libsecret

ดาวน์โหลดCozySafe-linux-x64.tar.gz
Android

ลงนามด้วยคีย์ของ Cozy Pi เมื่อ Android ถาม ให้อนุญาตให้เบราว์เซอร์ของคุณติดตั้งแอป

ดาวน์โหลดCozySafe-android.apk
iPhone

กำลังทดสอบผ่าน TestFlight ตอนนี้เฉพาะผู้ได้รับเชิญเท่านั้น
