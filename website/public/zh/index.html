Cozy Safe 如何保护你

你的数据不会以未加密的形式离开设备，负责加密的代码也完全公开。

在设备上加密

数据在写入磁盘之前就已加密，因此存放在云端文件夹中的备份同样是加密的。

密码加 Secret Key

你的密码会与保存在设备上的一个随机 128 位密钥组合使用，因此即使有人拿到你保险箱的副本，也无法猜出密码。

完全离线

Cozy Safe 无需联网。在 Android 上，它根本没有网络权限；在 macOS 上，它运行在无法联网的沙盒中。

屏幕上也不外露

密码和 Secret Key 在你点按“显示”之前始终隐藏，复制的内容 60 秒后自动清除，离开应用后保险箱会立即锁定。

备份由你掌控

将整个保险箱备份为一个加密文件，并在新设备上凭紧急恢复包还原。数据不会发送到我们的服务器，我们也没有服务器。

开源

任何人都可以阅读和检查代码（GPL-3.0）。安装包由 GitHub 构建，并附带可验证的来源证明。

使用前须知

无法找回

  • 如果忘记密码，任何人都无法再打开保险箱，包括我们。
  • 请选择一个你记得住的密码，例如由几个词组成的短语。

它做不到的事

  • 设备间暂不支持同步：请经常备份到文件。
  • 无法保护已经感染恶意软件的设备。
  • 任何知道密码的人都能打开保险箱。
