Cozy Safe

隐私政策

最后更新：2026-10-19

简要说明

Cozy Safe 不会收集、发送或出售你的任何数据。应用中没有账号、没有分析统计、没有广告，也没有跟踪。

你放入保险箱的所有内容都在你的设备上加密。我们无法读取这些内容，也没有任何副本。

保存在你设备上的内容

你的保险箱、笔记、文件和照片，始终使用由你的密码和 Secret Key 派生的密钥加密。

应用设置，例如语言以及浅色或深色模式。

数据可能去往的地方（仅在你选择时）

同步和备份使用你选择的文件夹或设备（例如 iCloud 云盘、Google 云端硬盘、Dropbox，或你网络中的其他设备）。写入其中的只有加密数据，你选择的服务提供方无法读取。

如果你开启 Secret Key 同步，Secret Key 会存储在你所用平台的端到端加密密码库中（iCloud 钥匙串或 Google 密码管理工具），并受该服务提供方的隐私条款约束。

当你在其他应用中分享、导出或打开某个项目时，该应用会收到一份未加密的副本，并按其自身条款处理。

权限

相机：仅在你打开相机时，用于将照片直接拍入保险箱。照片不会保存到你的相册。

生物识别：仅在你开启 Face ID、Touch ID 或指纹解锁时使用。你的生物识别数据绝不会离开设备的安全硬件，应用也始终无法获取。

本网站

safe.cozypi.com 是由 Cloudflare 提供服务的一组静态页面。本网站不设置 Cookie，也不运行任何分析统计。出于安全目的，Cloudflare 可能会根据其自身的隐私政策保留标准技术日志（例如 IP 地址）。下载文件由 GitHub 提供。

儿童

Cozy Safe 并非面向 13 岁以下的儿童，且不会收集任何人的数据。

变更与联系方式

如果本政策发生变更，新版本将发布在本页面并注明新的日期。

如有疑问：support@cozypi.com。Cozy Safe 由独立工作室 Cozy Pi 开发，源代码公开于 github.com/cozy-pi/cozysafe。
